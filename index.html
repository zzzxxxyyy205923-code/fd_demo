LOCAL DATA MIRROR MISSING

本地数据镜像缺失

当前以 file:// 方式直接打开页面。浏览器在这种模式下禁止读取本地 JSON，站点会自动改用内置镜像 assets/js/data.bundle.js，但该文件不存在或已损坏。

  1. 在项目根目录生成镜像：python3 tools/build_data_bundle.py
  2. 刷新页面即可正常浏览；也可改用本地服务：python3 -m http.server 8931

镜像由脚本从 assets/data/*.json 自动生成，请勿手工编辑；修改数据后需重新生成一次。

DATA LOAD FAILED

数据加载失败

页面已通过 HTTP 打开，但未能读取 assets/data/*.json，本地镜像也不可用。请确认预览服务仍在运行，且数据文件未被移动或改名。

  1. 重新启动预览服务：python3 -m http.server 8931
  2. 打开 http://localhost:8931/index.html 后刷新页面

若仍失败，可在浏览器控制台的 Network 面板查看具体失败请求；也可双击 index.html 改走本地镜像。
